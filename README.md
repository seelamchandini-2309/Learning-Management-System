# Learning Management System (LMS) 🎓

## 📌 Project Overview

A simple and user-friendly Learning Management System website developed using HTML5 and CSS3.

This project provides a structured website interface where users can explore courses and access contact information.

## ✨ Features

- Home page with a clean website layout.
- Courses page to display available courses.
- Contact page for user inquiries.
- Simple and user-friendly navigation.
- Organized and structured web pages.
- Responsive website design.

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📂 Project Structure

```text
Learning-Management-System/
│
├── index.html
├── courses.html
├── contact.html
│
└── css/
    └── style.css
```

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/seelamchandini-2309/Learning-Management-System.git
   ```

2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Explore the website.
